# References

Iris's statistical recommendations rest on published method, not house
preference. Every rule in [Choosing a test](../test/choosing.md),
[Reading the result](../test/interpreting.md), and
[Troubleshooting](../troubleshooting.md) traces to a source below. A
machine-readable version lives in [`stats-recommendations.bib`](../../stats-recommendations.bib),
alongside the guide; its DOI-bearing entries were generated from each DOI with
doi2bib.org.
