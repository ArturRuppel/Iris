# Quickstart

The quickest way to learn Iris is to build one analysis. This short tutorial
walks the whole shape of the tool inside the app: import a table, make a plot,
read the test Iris suggests. It takes about five minutes and drives the real
interface, so everything you do is the actual app, not a demo, on a real dataset.

You will use two of the app's three views: **Data**, where the table lives, and
the **Workbench**, where the analysis is built. The tutorial opens each at the
right moment and points you at the next step.

[Start the tutorial](iris-tutorial:quickstart)

When you finish, the analysis stays behind: a two-group comparison of petal
length across two iris species, ready to explore, edit, or save as a `.iris`
file. From there the rest of this guide covers shaping tables, working with more
than one table, and refining figures.

Prefer a finished analysis to poke at? [Open one in Iris](iris-open:iris-species-comparison)
and explore the same figure and numbers by hand.
