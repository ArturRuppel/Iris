Two table nodes feed the ⨝ join hub — the main pipeline (left) and the second table (right). The right input is itself a node, so it can carry its own reduce/collapse steps (e.g. collapse to a per-cell median) before the merge. One arrow flows out: the joined table, axes from the left, with the right's new value broadcast in.
