grid_complete — densify a ragged axis with honest zeros

§5 event-rate landscape. You count transition events per position. The trap: a transition that never happened at a position simply has no row — so its rate looks undefined instead of zero. grid_complete fills the full grid.

The full grid is every position × every declared transition level {A→B, B→C, C→A}. Observed combos get their event count; the three combinations that never occurred (purple rows) become a real 0 — not a missing row.
⚠ Without it, a plain group-and-count omits the purple rows. Then "mean events per transition" averages over only what happened — and every rate is biased upward. The zeros are the honest denominator.

The transition axis goes from ragged (only observed levels appear, varying by position) to dense (every position carries all 3 declared levels). A count value appears. This is the one op that makes the implicit array rectangular and explicit.
How it differs from pivot
Both touch a categorical axis, opposite directions: pivot removes the axis (its levels become columns); grid_complete keeps the axis but fills it dense (its levels become guaranteed rows, with 0s). Pivot widens; grid_complete lengthens.
The knobs Iris exposes
  • by — the id columns that stay as axes (experiment, position) — the grid is these crossed with every level.
  • column — the categorical to complete (transition).
  • levels — the declared universe of levels {A→B, B→C, C→A}. This is the crux: you assert the full set, so a level that never appears anywhere still gets its 0 rows. Not inferred from the data.
  • count_unique — optional: dedup an id before counting (e.g. count distinct cells that did the transition, not raw events).
  • fill = 0 — what an absent combination becomes.
  • count_name = count — the new value column's name.
