pivot — a categorical axis becomes named value columns (unstack)

Long → wide. You have one row per cell × feature; pivot gives you one row per cell with perimeter and area side by side — so you can combine them.

Each level of feature (the teal cells) becomes a column. Two rows per cell collapse into one wider row. The values that were stacked in measure are now spread across named columns.

The feature axis is removed from the dimensions; one new value per level takes its place. This is the inverse of how tidy data stacks measurements — and it's the only way to get two measured columns onto the same row so an op like derive can combine them.
Why you'd do it — the §4 shape factor
perimeter area → derive  q = perimeter / √area → q shape factor, by class → box plot
Pivot exists to set up the derive: perimeter and area must sit on one row before you can divide them. Pivot then derive is the canonical pair.
The knobs Iris exposes
  • index — the keys that stay as axes (experiment, position, cell) — one output row per combination.
  • column — the categorical to unstack (feature) — its levels become columns.
  • values — the measure to spread (measure).
  • names — maps each level to its new column name (perimeter, area); an unmapped level is dropped.
  • agg = sum — if several rows land in the same (index × level) cell they're combined (default sum). One row each → it's a pure reshape.
  • fill = 0 — an absent (index × level) combination becomes this, not missing.
